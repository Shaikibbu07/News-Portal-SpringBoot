# TV7ibbu - News Portal Application

TV7ibbu is a modern full-stack news portal developed using Spring Boot and MySQL. The application provides a clean and responsive interface for browsing news articles across multiple categories such as Technology, Sports, Lifestyle, World, and Business.

## Features

* Category-based news browsing
* Search functionality
* Breaking news ticker
* Featured articles section
* Responsive user interface
* Advertisement placement support
* Dynamic article management
* Clean magazine-style layout

## Tech Stack

### Backend

* Java
* Spring Boot
* Spring Data JPA
* Hibernate

### Frontend

* HTML5
* CSS3
* JavaScript
* Thymeleaf

### Database

* MySQL
